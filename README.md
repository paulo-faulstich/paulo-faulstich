## Current focus

I care about whether a system solves a useful problem, how it behaves when things go wrong, and what it costs to operate.

## Selected projects

### [Hedera STAR Loyalty](https://github.com/paulo-faulstich/hedera-star-loyalty)

A loyalty token prototype on Hedera testnet using HTS and HCS, with custom fees, audit logging, and a dashboard. Connects an executable prototype to product requirements and architecture decisions.

### [EV ChargeOps](https://github.com/paulo-faulstich/ev-chargeops)

An academic prototype for shared EV charging operations: import charging records, attribute sessions, review anomalies, and generate auditable invoices. Built with Python/FastAPI and TypeScript/Next.js for the GoodWe + FIAP Enterprise Challenge.

## How I work

Start with the user's problem. Build a small version to test the assumptions. Examine the evidence, explain the trade-offs, and use what changed to inform the next product decision.
